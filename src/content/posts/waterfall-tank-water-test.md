[1편 세팅 계획](/posts/waterfall-tank-setup/)을 세운 뒤, 돌과 소일을 넣기 전에 물만 채워 이틀을 두었습니다. 돌을 쌓고 소일을 깐 다음에 물이 새거나 받침이 기울면 전부 다시 꺼내야 해서, 빈 어항일 때 확인하는 게 가장 쉽습니다.

## 왜 물만 먼저 채웠나

확인하고 싶은 것은 네 가지였습니다.

- 어항 바닥 둘레에서 물이 새지 않는지
- 어항을 올린 책꽂이가 물 무게에 처지거나 기울지 않는지
- 아무 장비도 없을 때 수온이 방 온도와 얼마나 차이 나는지
- 뚜껑을 덮었을 때 물이 하루에 얼마나 줄어드는지

뒤의 두 가지는 나중에 펌프를 넣고 폭포를 돌릴 때 비교할 기준값입니다. 펌프가 물을 얼마나 데우는지, 폭포가 증발을 얼마나 늘리는지는 기준값이 있어야 알 수 있습니다.

## 조건

| 항목 | 내용 |
| --- | --- |
| 어항 | 가로 35 × 폭 23 × 높이 25cm |
| 수위 | 12cm (유리 바깥에 표시) |
| 물의 양 | 약 9L |
| 들어간 것 | 디지털 수온계만. 펌프, 돌, 소일 없음 |
| 뚜껑 | 덮음 |
| 받침 | 책꽂이 상판 위에 매트 |
| 기간 | 물 채운 뒤 1일차, 2일차에 확인 |

![물을 12cm 채운 어항 옆모습과 수온계](/images/posts/water-test/side-thermometer.jpg)

## 결과

| 항목 | 1일차 | 2일차 |
| --- | --- | --- |
| 누수 | 없음 (바닥 둘레, 매트 마름) | 없음 |
| 책꽂이 수평 | 물 채우기 전과 같음 (폰 수평계) | 같음 |
| 수온 | 23.6℃ | 23.6℃ |
| 방 온도 / 습도 | 25.5℃ / 40.9% | 24.7℃ / 43.2% |
| 수면 높이 | 표시선과 눈으로는 차이 없음 | 표시선보다 2mm 낮음 (자로 잼) |

![방 온도와 습도](/images/posts/water-test/room.jpg)

누수와 수평은 문제없었습니다. 다 채우면 20~25kg쯤 될 텐데, 물 9L로는 상판에 변화가 없었습니다. 돌과 소일을 넣은 뒤에도 한 번 더 확인할 생각입니다.

증발은 첫날에는 눈으로 차이가 보이지 않아 하루를 더 기다렸고, 이틀째에 자를 대 보니 수면이 표시선보다 2mm 내려가 있었습니다. 뚜껑을 덮은 상태에서 하루 약 1mm인 셈입니다. 바닥 면적이 35×23cm라 1mm는 물 약 80mL이니, 하루에 작은 컵 반 잔 정도가 날아가는 정도입니다.

![12cm 표시선과 이틀 뒤 수면을 자로 잰 모습](/images/posts/water-test/ruler-day2.jpg)

이틀째 수면 높이에 새 표시(+2Day)를 붙여 두었습니다. 펌프를 넣은 뒤에도 같은 방법으로 재면, 물이 움직일 때 증발이 얼마나 늘어나는지 비교할 수 있습니다.

## 물이 방보다 낮았던 이유

첫날 물은 방보다 1.9℃ 낮았고, 이틀째에는 차이가 1.1℃로 줄었습니다. 받아 둔 수돗물이 아직 방 온도를 따라가는 중이고, 수면에서 물이 조금씩 증발하며 열을 가져가기 때문입니다. 히터나 펌프 없이 물만 둔 어항에서는 흔한 일입니다.

펌프를 넣은 뒤 이 차이가 줄어들거나 물이 방보다 따뜻해지면, 그만큼이 펌프 모터에서 나온 열입니다.

## 유리에 붙은 작은 기포

![12cm 수위 표시와 유리, 바닥에 붙은 작은 기포](/images/posts/water-test/label-bubbles.jpg)

하루 뒤 유리 벽과 바닥에 작은 기포가 잔뜩 붙어 있었습니다. 차가운 수돗물에 녹아 있던 공기가 물이 데워지면서 빠져나온 것으로, 물에 문제가 있다는 뜻은 아닙니다. 물이 돌지 않아서 그대로 붙어 있을 뿐이고, 손으로 쓸어 내거나 펌프를 돌리면 며칠 안에 사라집니다.

## 다음 기록

3W 펌프(최대 370L/h)를 같은 물에 넣고 하루 돌려, 수온과 증발이 오늘 기준값에서 얼마나 달라지는지 비교합니다. 그다음에 화산석과 편석을 쌓아 폭포 물길을 시험합니다.
